# Contributing to CBT Application

We welcome contributions from everyone! Please follow these guidelines to ensure a smooth process.

## How Can I Contribute?

### Reporting Bugs
- Use the **Bug Report** issue template.
- Describe the steps to reproduce the issue.
- Include information about your environment (OS, browser, PHP version).

### Suggesting Enhancements
- Use the **Feature Request** issue template.
- Describe the problem you're trying to solve and the proposed solution.

### Code Contributions
1. Fork the repository.
2. Create your feature branch.
3. Follow the [Development Standards](./development-standards.md).
4. Submit a Pull Request.

## Code of Conduct

Maintain a respectful and inclusive environment. Avoid any form of harassment or discrimination.

## Development Rules

- **No direct commits to `main` or `develop`**: Always use a feature branch.
- **Tests**: Include unit or feature tests for new functionality.
- **Documentation**: Update relevant documentation if you change an existing feature or add a new one.
- **Clean Code**: Delete commented-out code and unused imports before submitting.
